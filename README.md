# 📦 RentMate — KITCOEK Student Marketplace

An exclusive student-to-student marketplace for **KITCOEK** (Kolhapur Institute of Technology's College of Engineering) to buy, sell, and rent academic tools, books, calculators, and hostel gear.

---

## ⚡ Quick Features
- **Verified Student Access:** Student ID upload with Admin verification badges (`✅ Verified KITCOEK Student`).
- **Buy & Rent Listings:** Post items to SELL or RENT (per day/month + deposit) with **`🏷️ SOLD OUT`** toggles.
- **Real-Time Chat:** Socket.IO instant messaging between buyers & sellers.
- **Privacy First:** Mobile numbers and emails strictly hidden from public profiles & listings.
- **Cloud Storage & Design:** Cloudinary image hosting, Google Inter typography, 60fps loading animations, and user-friendly error alerts.

---

## 🚀 Getting Started

### 1. Backend (`/server`)
```bash
cd server
npm install
node server.js
```

### 2. Frontend (`/client`)
```bash
cd client
npm install
npm run dev
```

---

## 🛠️ Tech Stack
- **Frontend:** React 19, Vite, Socket.IO Client, Axios, Lottie-React
- **Backend:** Node.js, Express.js, MongoDB Atlas, Socket.IO Server, JWT, Cloudinary SDK
